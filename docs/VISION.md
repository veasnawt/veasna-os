# Rixie Vision — The AI Operating System for Veasna OS

## Vision Statement
Rixie is the cognitive engine, operating system companion, and persistent creative partner at the core of **Veasna OS**. 

She synthesizes three powerful paradigms into one unified AI system designed specifically for creative production:

1. **Jarvis (System Companion & Proactive Control)**: Ambient awareness, workspace automation, background task monitoring, system diagnostics, and hardware/studio orchestration.
2. **Claude Code (Agentic Execution & File System Mastery)**: Deep workspace understanding, multi-file code editing, terminal execution, self-correcting loop, and file manipulation across all studios.
3. **ChatGPT (Conversational & Creative Partner)**: Fluid natural dialogue, creative brainstorming, storytelling, structured planning, and multi-modal synthesis.

---

## The 4 Core Architectural Capabilities

### 1. Provider-Agnostic Intelligence Layer
- Seamless runtime switching across Anthropic (`claude-sonnet-5`), OpenAI (`gpt-4o`), Google Gemini (`gemini-2.0-flash`), and local Ollama (`llama3.1`).
- Zero vendor lock-in with standard `LLMProvider` interface.

### 2. Universal Hybrid Memory Engine
- Persistent SQLite storage (`memory.db`) shared across all studios.
- Semantic vector embeddings + keyword hybrid search.
- Cross-studio asset linking (Video Scene ↔ Music Track ↔ Digital Art Asset ↔ Game Sprite).

### 3. Agentic Execution & Studio Control (Claude Code capabilities)
- Direct filesystem inspection and modification within `veasna-os`.
- Safe command execution for rendering, audio processing, and script building.
- Self-correcting tool execution loop.

### 4. Multi-Studio Co-Creation (Jarvis capabilities)
- **BP Studio**: Automated video scriptwriting, scene planning, video rendering triggers.
- **Art Studio**: Style prompt generation, asset organization, canvas actions.
- **Music Studio**: Lyric generation, track scoring, stems management.
- **Game Dev Studio**: Game mechanics design, sprite generation, level scripting.
